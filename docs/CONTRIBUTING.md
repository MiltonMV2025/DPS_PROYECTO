# Contribuir

## Flujo de ramas

- Crear ramas siempre desde `develop`.
- Usar nombres `feature/*`, `fix/*` o `chore/*`.
- Abrir Pull Request obligatoriamente hacia `develop`.
- No hacer commits directamente en `main`.

## Commits

Mantener commits pequeños, descriptivos y enfocados en una sola responsabilidad. Antes del PR ejecutar `npm run lint`, `npm run typecheck` y `npm run build`.
